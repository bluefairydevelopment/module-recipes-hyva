BlueFairy_RecipesHyva — Marketing Content
==========================================


3-SENTENCE SUMMARY
------------------

BlueFairy_RecipesHyva is the Hyvä theme companion for BlueFairy_Recipes, free and open source under the MIT licence. It replaces all 14 Luma frontend templates with Tailwind CSS and Alpine.js equivalents, giving you a keyword search and filters on the recipe listing that submit themselves, reactive add-to-cart feedback for ingredient linking, and an off-canvas affiliate drawer. No layout XML changes are needed: a single TemplateResolver plugin auto-swaps templates when the Hyvä theme is active.

    <h2>What You Get</h2>
    <ul>
      <li><strong>14 Hyvä templates</strong> — recipe listing, recipe detail, writer listing, writer profile, ingredients, steps, nutrition, schema (JSON-LD), reviews, social share, submission form, featured widget, the product page tab, and the affiliate drawer. All rendered with Tailwind CSS utility classes.</li>
      <li><strong>Self-submitting filter and search</strong> — the recipe listing reloads with the results about 600 ms after keyword typing stops and 250 ms after a taxonomy filter changes, so no button needs pressing.</li>
      <li><strong>Reactive add-to-cart</strong> — Alpine.js manages the ingredient "Add Store Ingredients to Cart" button state: idle → loading spinner → success tick. No full-page refresh.</li>
      <li><strong>Off-canvas affiliate drawer</strong> — affiliate ingredient links open in a smooth slide-in panel (links in the drawer carry <code>rel="nofollow"</code>; the links in the ingredient list carry <code>rel="sponsored"</code>). Opens as a dialog, closes with the Escape key and on an outside click.</li>
      <li><strong>Hyvä-native layout handles</strong> — three dedicated handles (<code>hyva_blue_recipe_index_index</code>, <code>hyva_blue_recipe_index_view</code>, <code>hyva_blue_recipe_index_submit</code>) for Hyvä-specific layout targeting.</li>
      <li><strong>Zero configuration</strong> — the <code>TemplateResolver</code> plugin detects the active theme and swaps templates automatically. No admin config changes or layout XML edits needed.</li>
    </ul>

    <h2>How It Works</h2>
    <ol>
      <li><strong>Install</strong> via Composer alongside the core module: <code>composer require bluefairy/module-recipes bluefairy/module-recipes-hyva</code></li>
      <li><strong>Enable</strong> both modules: <code>bin/magento module:enable BlueFairy_Recipes BlueFairy_RecipesHyva</code></li>
      <li><strong>Run</strong> <code>setup:upgrade && setup:di:compile && cache:flush</code>. The companion is live.</li>
      <li><strong>Rebuild the theme CSS</strong>: run <code>bin/magento hyva:config:generate</code>, then your theme's Tailwind build. The module registers its own Tailwind source, so no manual source paths are needed.</li>
    </ol>
